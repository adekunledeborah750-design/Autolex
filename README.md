# Autoluxe Automotive — Luxury Atelier Website

A bespoke luxury automotive atelier website inspired by [Forge Automotive](https://forgeautomotive.co.uk/), meticulously crafted with **"Autoluxe"** branding while preserving every single section, detail, service, vehicle archive, and interactive feature in full fidelity.

---

## 💎 Project Features

- **Brand Aesthetic & Palette**:
  - Jet Black (`#0C0C0C`), Deep Claret (`#410306`), Champagne Bronze (`#C5A064`), and Warm Platinum (`#F2F1ED`).
  - High-contrast editorial typography: *Playfair Display* serif headings and *Plus Jakarta Sans* geometric body.
  - Micro-interactions, animated brand marquee ribbon, luxury button shine effects, and glassmorphism.

- **Full Page Architecture**:
  1. **Home**:
     - Cinematic Hero (*"For Those Who Refuse Ordinary — We don’t modify vehicles, we build them for you"*).
     - 3-Pillar Philosophy (*Identity, Insight, Cohesion*).

     - Marquee Ribbon with luxury marques (*Porsche, Lamborghini, Aston Martin, Bentley, Rolls-Royce, Ferrari, Land Rover, McLaren, Mercedes-AMG*).
     - Featured Builds & Stock highlights.
     - Signature Atelier Call to Action (*"Refuse Ordinary"*).
  2. **Builds Archive (`/builds`)**:

## 🚀 How to Run

### Option 1: Live Development Server (React + Vite + Tailwind)
```bash
cd C:\Users\USER\.gemini\antigravity\scratch\autoluxe
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Option 2: Production Build
```bash
npm run build
npm run preview
```

### Option 3: Instant Standalone (No Node.js Required)
Double-click `standalone_preview.html` to open it directly in any web browser.
